五竜ダウンヒル

左に曲がりたいときは右足（外足）に荷重。画面の右側をホールドすると、じわっとエッジが立って左へカーブします。地形は国土地理院の標高データから作った実際の五竜です。

コースを選ぶ

距離・標高差・最大斜度は実地形での実測値。看板の「公式」値はエイブル白馬五竜のコースガイドより。コース線はOpenStreetMapのデータをつないだもので、区間の境目はおおよそです。PCは ← / → キー（左足 / 右足）、↓ でブレーキ、↑ で漕いで加速。
